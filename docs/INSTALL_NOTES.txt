Orax Hotel — مُثبّت Windows المتكامل (v1.0.0)
===============================================

ما يقوم به OraxHotel-Setup.exe:

1) يثبّت التطبيق وملفات الواجهة والتقارير والملحقات داخل:
   %LOCALAPPDATA%\OraxHotel

2) يفحص خدمة SQL Server ويحاول تشغيلها إن كانت متوقفة.
   الخادم الافتراضي: .\SQLEXPRESS
   الحساب الافتراضي: sa  /  orax055266
   (كل القيم في installer-config.json قابلة للتعديل قبل البناء)

3) ينسخ النسخة الاحتياطية Hotel_alkheer20232009552241.bak إلى:
   %ProgramData%\OraxHotel\Database
   ثم يستعيدها إلى قاعدة Hotel_alkheer إن لم تكن موجودة.

4) يكتب appsettings.json الكامل بكل connection strings المطلوبة:
   cc, Hotel_alkheerContext, cc0, cc1, cc2, HotelDb_2Context0..2
   (كلها تشير إلى نفس قاعدة البيانات المحلية المُستعادة)

5) يُنشئ حساب مشرف افتراضي داخل dbo.AspNetUsers (إن لم يوجد):
   اسم المستخدم: admin
   كلمة المرور: Admin@2024!
   البريد:      admin@oraxhotel.local
   (يُنصح بتغييرها بعد أول دخول)

6) يُنشئ اختصار Orax Hotel على سطح المكتب.

7) يفتح منفذ 5080 في جدار حماية Windows.

8) يُشغّل التطبيق تلقائياً ويفتح المتصفح على:
   http://localhost:5080

بيانات الدخول بعد فتح التطبيق:
- اسم المستخدم: admin
- كلمة المرور:  Admin@2024!
(أو حساب المشرف الموجود مسبقًا في النسخة الاحتياطية إن كنتم تفضلون استخدامه)

أوضاع التشغيل:
- الوضع الصامت (الافتراضي): OraxHotel-Setup.exe
- الوضع التفاعلي:           OraxHotel-Setup.exe --interactive
- الوضع التفصيلي:           OraxHotel-Setup.exe --verbose

المتطلبات:
- Windows 10/11 x64
- SQL Server 2019+ أو SQL Server Express 2019+ (يثبّت منفصلاً إن لم يوجد)
- تنزيل SQL Server Express: https://www.microsoft.com/en-us/sql-server/sql-server-downloads
- صلاحيات Administrator مُفضّلة لفتح منفذ جدار الحماية

إزالة التطبيق:
شغّل uninstall-oraxhotel.cmd من مجلد:
%LOCALAPPDATA%\OraxHotel
(لا يحذف قاعدة البيانات من SQL Server — احذفها يدوياً إن لزم)

تنبيه أمني:
- ملف installer-config.json يحوي كلمات مرور فعلية. لا ترفعه إلى مستودع عام.
- غيّر كلمة مرور sa على خوادم الإنتاج قبل أي نشر علني.
- استخدم حزمة مُخصّصة لكل عميل عند التوزيع التجاري.
