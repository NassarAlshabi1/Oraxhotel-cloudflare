OraxHotel-Setup.exe — ملاحظات الإصدار والتثبيت الآمن
=====================================================

الحزمة الحالية مبنية كـ Windows x64 self-contained وتضمّن:
- HotelSys.exe وملفات wwwroot.
- وسيط SQL Server 2022 Express Core x64 داخل EXE النهائي.
- نسخة Hotel_alkheer الاحتياطية وملف SQL البديل.
- 7zr.exe وملفات الإعداد اللازمة للاستخراج.

المتطلبات:
- Windows 10 أو Windows 11 بنظام 64-bit.
- صلاحية Administrator عبر UAC.
- مساحة إضافية كافية لاستخراج الوسيط والحمولة وتثبيت SQL Server Express.
- لا يلزم تثبيت SQL Server مسبقاً؛ إذا وُجدت نسخة .\SQLEXPRESS قابلة للاتصال يحافظ المُثبّت عليها.

التشغيل:
1. شغّل OraxHotel-Setup.exe واختر قبول مطالبة UAC.
2. يثبت المُثبّت SQL Server Express باسم SQLEXPRESS عند الحاجة.
3. يستخرج التطبيق ويستعيد Hotel_alkheer من ملف .bak إذا لم تكن القاعدة موجودة.
4. يكتب appsettings.json باتصال Windows المحلي، وينشئ اختصار Orax Hotel.
5. افتح الاختصار للوصول إلى http://localhost:5080.

بيانات الدخول:
- لا توجد بيانات اعتماد افتراضية في هذا الملف.
- استخدم اسم المستخدم وكلمة المرور الأصليين لحساب المشرف الموجود في النسخة الاحتياطية داخل dbo.AspNetUsers.
- لا ينشئ المُثبّت admin جديداً ولا يغير PasswordHash.
- يحتفظ الكود بتوافق احتياطي للحسابات القديمة في dbo.admin_table فقط إذا كانت بياناتها موجودة في قاعدة المالك.

التحقق بعد التثبيت:
- خدمة SQL Server: MSSQL$SQLEXPRESS.
- قاعدة البيانات: Hotel_alkheer.
- التطبيق: %LOCALAPPDATA%\OraxHotel\HotelSys.exe.
- الإعدادات: %LOCALAPPDATA%\OraxHotel\appsettings.json.
- الاختصار: %USERPROFILE%\Desktop\Orax Hotel.lnk.

ملاحظات مهمة:
- إذا فشلت استعادة .bak، يوقف المُثبّت العملية ولا يستبدلها تلقائياً بقاعدة SQL بلا مستخدم.
- ملف Hotel_alkheer_init.sql بديل للمخطط والبيانات العامة فقط، ولا ينشئ حساب مشرف.
- لا تضع كلمات مرور SQL أو التطبيق أو رموز GitHub في GitHub أو ملف الإعدادات.
- لا يمكن اعتماد نجاح تشغيل EXE أو RESTORE التنفيذي من بيئة Linux؛ يجب إجراء اختبار قبول على Windows بعد نشر الإصدار.
