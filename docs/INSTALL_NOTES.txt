Orax Hotel — مُثبّت Windows

ما يقوم به OraxHotel-Setup.exe:

1) يثبت التطبيق وملفات الواجهة والتقارير والملحقات داخل:
   %LOCALAPPDATA%\OraxHotel

2) يطلب اسم خادم SQL Server. القيمة الافتراضية:
   .\SQLEXPRESS

3) يطلب نوع المصادقة. يفضل استخدام Windows Authentication على جهاز SQL Server المحلي. يمكن اختيار SQL Authentication إذا كان ذلك هو إعداد الخادم.

4) ينسخ نسخة قاعدة البيانات الموجودة إلى:
   %ProgramData%\OraxHotel\Database
   ثم يستعيد قاعدة Hotel_alkheer إذا لم تكن موجودة.

5) لا ينشئ حساب admin جديدًا ولا يضع كلمة مرور افتراضية. حساب المشرف/صاحب النظام الموجود داخل النسخة الاحتياطية يبقى كما هو، وتُستخدم بيانات دخوله الأصلية عند فتح التطبيق.

6) يكتب appsettings.json بعد الاستعادة باستخدام اتصال الخادم الذي أدخله المستخدم. لا توجد كلمات مرور أو عناوين خادم حقيقية داخل payload قبل التثبيت.

7) ينشئ اختصار Orax Hotel على سطح المكتب. عند فتحه يبدأ التطبيق محليًا على:
   http://localhost:5080

المتطلبات:

- يجب أن يكون SQL Server أو SQL Server Express مثبتًا ويعمل على الجهاز أو أن يكون الخادم متاحًا عبر الشبكة.
- يجب أن يملك حساب التثبيت صلاحية الاتصال وإنشاء/استعادة قاعدة بيانات.
- الاستعادة لا تستبدل قاعدة Hotel_alkheer الموجودة مسبقًا؛ إذا كانت القاعدة موجودة، يحافظ المُثبّت عليها.
- لم يتم استخراج كلمة مرور المشرف من النسخة الاحتياطية، ولم تُطبع أو تُضمّن في المُثبّت.
- يجب اختبار الاستعادة على Windows قبل الاستخدام الإنتاجي. البيئة الحالية Linux ولا تشغّل ملفات EXE أو SQL Server فعليًا.

إزالة التطبيق:

شغّل uninstall-oraxhotel.cmd من مجلد:
%LOCALAPPDATA%\OraxHotel

تنبيه:

المُثبّت لا يتجاوز تراخيص DevExpress أو أي مكوّن خارجي. كما ينبغي أخذ نسخة احتياطية من أي قاعدة بيانات موجودة قبل التثبيت أو التحديث.
